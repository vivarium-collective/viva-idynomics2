Biofilm baseline

simple.xml — surface-attached biofilm, fixed boundary feed

30 bacteria seeded on the bottom of a 32x64um 2D domain. Each step (3 min) the PDE wrapper diffuses solute + oxygen, agents consume and grow, then the relaxation pushes them apart. We track the compartment-averaged concentrations and the agent population.

Full simulator state — 3D / 4D views

Read straight from the JVM after each step. The 2D solute grid animates over time (3D x-y-t view); the final solute field is also rendered as a 3D surface where height encodes concentration; and the agents are shown as a 4D scatter (positions × time × mass).

protocol: biofilm-baseline interval: 180 min total: 7200 min wall: 1.71 s snapshots: 41

Chemostat — natural decay

chemostat.xml — dimensionless tank, first-order reaction

Dimensionless tank with two solutes and a first-order reaction solute1 → 0.5 · solute2. No agents, no boundary feed — solute1 decays exponentially, solute2 accumulates. iDynoMiCS's ChemostatSolver integrates the ODE.

protocol: chemostat-natural interval: 1 min total: 50 min wall: 0.08 s snapshots: 51

Chemostat — pulsed external feed

chemostat.xml driven by the PBG input port

Same chemostat compartment, but the bigraph pulses solute1 back up to 2.0 every 10 simulated units (via the external_concentrations input port). iDynoMiCS still integrates the decay between pulses — so the coupling is bidirectional within the simulator's own step.

protocol: chemostat-pulsed interval: 1 min total: 50 min wall: 0.08 s snapshots: 51

Architecture

The wrapper exposes a single Process that drives the upstream idynomics.Simulator via JPype. Inputs push absolute external concentrations down into iDynoMiCS; outputs come back as composable deltas (so a sibling kinetic process can also write to the same store).

Composite document (representative)

This is the shape of the PBG document constructed for each run — the bridge connects to four stores (external_concentrations, average_concentrations, population, time), and a RAMEmitter records the outputs.
